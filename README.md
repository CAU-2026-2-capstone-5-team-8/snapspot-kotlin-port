# SnapSpot Kotlin 이식본 (비교용)

팀 저장소 `snapspot`에 있는 코틀린 앱과는 **따로 만든 이식본**이에요. 같은 앱(저장한 장소와 프랜차이즈 쿠폰 근처에 가면 알림)을 `domain / data / di / ui` 구조로 옮긴 것이고, 패키지명(`com.capstone.snapspot`)이 같아서 두 앱을 한 기기에 같이 설치할 수 없어요.

이 저장소는 비교와 의견 교환을 위한 것이라, 아래 순서로 PR을 하나씩 열어 채워 가요.

1. `docs/` : 프로토타입(지도 매핑, 위젯) 계획과 진행 기록
2. 코틀린 앱 기준선
3. CI (`.github/workflows/android.yml`)
4. 지도 매핑 프로토타입

각 PR의 설명에 무엇을 왜 올리는지, 무엇을 확인했고 무엇을 확인하지 못했는지 적어 둘게요.

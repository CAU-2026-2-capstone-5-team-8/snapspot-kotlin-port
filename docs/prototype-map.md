# 프로토타입 1: 지도 매핑 — 단계와 진행 추적

상위 계획: [prototype-overview.md](prototype-overview.md) · 다른 기능: [prototype-widget.md](prototype-widget.md)
코드 위치: 이 저장소의 `app/`. 한글이 들어간 경로에서는 AGP가 빌드를 막으므로 영문 경로에 클론해서 작업한다.
마지막 갱신: 2026-10-13

## 목적

앱을 열면 쿠폰을 쓸 수 있는 지점이 지도에 보이고, 눌러서 쿠폰으로 갈 수 있게 한다. 알림이 없어도 보이는 경로다. 프로토타입이라 **동작하는 뼈대를 먼저** 만들고, 디자인·수치·예외 처리는 나중에 다듬는다.

## 이 기능의 원칙

- 새 로직은 새 파일에만 둔다 (`domain/MapBranches.kt`, `domain/MapFollow.kt`, `ui/map/MapBranchViewModel.kt`). 기존 파일은 꼭 필요한 연결만 덧붙인다. 기존 함수의 동작·시그니처는 바꾸지 않는다.
- `buildWindow`는 고치지 않는다. 지점 id 형식 `"b|key|kakaoId"`만 맞춘다.
- 알림, 지오펜스, 장소 탭, 쿠폰 화면의 동작은 바뀌면 안 된다.
- 기존 테스트는 수정하지 않고 통과해야 한다. 고쳐야 하는 상황이 생기면 진행을 멈추고 알린다.
- 활성 쿠폰(사용·만료 제외)이 하나도 없는 브랜드의 배지는 지도에 두지 않는다. 눌러도 아무 일도 없는 배지는 남기지 않는다.
- 종료된 장소(`suppressReason == ENDED`)는 지도에서 뺀다. 흐리게 표시하지 않고, 저장 목록(장소 탭)에서는 지우지 않는다.
- 지도는 기본으로 내 위치를 따라간다. 앱이 옮긴 이동은 "이 지역에서 다시 탐색" 버튼을 띄우지 않는다. 손으로 옮기거나 확대·축소하면 따라가기를 멈추고 버튼을 보여 준다. "내 위치로"를 누르면 다시 따라가고 버튼은 숨긴다.
- 장소 핀·카드를 눌러 포커스하면 따라가기를 멈추고 버튼은 띄우지 않는다.
- 조회는 버튼 + 줌 제한 + 기존 캐시(6시간)로 제한한다. 디바운스는 쓰지 않는다. 위치 추적은 지도 화면이 열려 있을 때만이고, 앱 전체의 위치 감시(장소 도착 알림용)는 그대로다.
- 커밋은 요청이 있을 때만 한다.
